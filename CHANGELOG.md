# История изменений

## [0.1.4] — улучшен сенсор дней периода

- Количество дней передаётся в Home Assistant как целое число; единица отображается по-русски с формой «день/дня/дней».
- Удалён бинарный сенсор доступности передачи показаний; при настройке удаляется его устаревшая запись из реестра сущностей.

---

## [0.1.3] — упрощена публикация релиза

- Удалена фиксированная двухминутная пауза в release workflow; перед подготовкой релиза сразу проверяется, что `main` всё ещё указывает на проверенный commit.
- Добавлены предоставленные владельцем `codeowners`, ссылки на документацию и issue tracker в manifest.

---

## [0.1.2] — раздельная проверка исходников и состояния релиза

- Обычные GitHub Actions-проверки больше не требуют наличия ранее собранного release-архива; строгая проверка запускается только после подготовки архива.
- Для самого первого выпуска release workflow создаёт baseline-архив на текущей версии manifest. Если релизные теги уже существуют, но build-state отсутствует, публикация останавливается, чтобы не выдавать полный снимок за delta.
- Добавлен тест CI-bootstrap сборщика и статические проверки отсутствия циклической зависимости в workflow.

---

## [0.1.1] — усиление проверок и обработка ошибок

- Ошибки авторизации и сетевого соединения больше не поглощаются как ошибки отдельных необязательных запросов; если все чтения лицевого счёта не удались, обновление помечается неуспешным.
- Убран широкий `except Exception` из настройки записи конфигурации, чтобы ошибки программирования не маскировались под временную недоступность API.
- Усилен локальный валидатор: проверка совпадения Config Flow/API-методов, отсутствие синхронного файлового I/O и широких обработчиков исключений, а также наличие и версионные ограничения сторонних зависимостей.
- Релизный workflow запускается только на `main`, ждёт успешных local/Hassfest/HACS-проверок, проверяет метаданные, номер версии и актуальность commit; ручной запуск и push тега не публикуют релиз.
- Добавлены тесты обработки сетевых ошибок, проверки методов Config Flow и запрета повторной публикации версии.

---

## [0.1.0] — начальная read-only версия

- Добавлена интеграция Home Assistant с одним полем телефона/email и автоматическим определением типа логина.
- Добавлены сущности для баланса, пеней, периода передачи показаний и распознанных последних показаний.
- Реализованы только авторизация и чтение данных; отправки показаний нет.
- Добавлены локальный валидатор, тесты, delta-сборщик и GitHub Actions.
