# История изменений

## [0.1.0] — начальная read-only версия

- Добавлена интеграция Home Assistant с одним полем телефона/email и автоматическим определением типа логина.
- Добавлены сущности для баланса, пеней, периода передачи показаний и распознанных последних показаний.
- Реализованы только авторизация и чтение данных; отправки показаний нет.
- Добавлены локальный валидатор, тесты, delta-сборщик и GitHub Actions.
